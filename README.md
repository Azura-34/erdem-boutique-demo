# Erdem Boutique — E-commerce Demo

Responsive storefront and PHP/MySQL administration demo built with HTML, CSS, JavaScript, PHP, and MySQL.

## Included

- Product catalog, product details, and cart
- PHP/MySQL product and order endpoints
- Admin sign-in, product management, and order dashboard
- Installation page and sample catalog data

## Status

This is a portfolio/demo snapshot, not a live store. Online payments are not integrated, and the contact, privacy, KVKK, distance-sales, and return pages contain placeholders that must be completed for the business. The sample WhatsApp contact link has been removed.

GitHub Pages cannot run the PHP/MySQL backend. To use this as a live store, deploy it on PHP/MySQL hosting, complete and review the payment and business/legal setup, and test it before accepting customer data or orders.

## Setup

See [README-V5.md](README-V5.md) for the current setup notes. Do not commit the generated `config.php`, `.installed` file, real customer data, or uploaded customer/product files.
